## StradaOS 2.10.1 — Set StradaOS as home with one tap

### New
- **Detects when StradaOS is not the default home app and offers a setup button.** Choose Set now, StradaOS, then Always. Android 10+ shows the home-role system dialog. Also offered after setup so the factory menu does not return on boot or Home presses.
- Settings → System → Home screen shows the current home app and **Open StradaOS on boot** for Android 4–9 units that always start their factory menu.
- Settings → Map and weather → Performance can **disable the live map** on slower units while retaining speed readings.
- Settings → Music includes help for Bluetooth audio that stops when leaving its app or is absent from the dashboard.
