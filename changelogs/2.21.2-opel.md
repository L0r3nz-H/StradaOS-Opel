# StradaOS Opel 2.21.2

Branch `feature/opel-latest-2.21.2` starts directly from upstream `b2f327dcfae5e8341cb7851c525dc893545b3ee2` dated 2026-11-15. Opel changes were ported from `feature/opel-navi900-theme`; that branch is preserved.

- Opel design, light/dark modes, transparent Astra J photo, and the optional four-shortcut compact dashboard are retained.
- Vehicle name above the photo; centered optional speed; name/photo centered together without speed. No compact navigation shortcut. Missing temperature remains hidden.
- Current upstream architecture remains: reorganized settings, maintenance, backups, dialogs, portrait standard layout, configurable dock, offline maps, and audio/Bluetooth fixes.
- Opel also supports scheduled/system themes, storing the mode separately in `opel_theme`.
- Compact GPS speed honors the new display correction. GPS/media/weather callbacks tolerate standard widgets absent in compact mode.
- APK name `StradaOS Opel`, package `com.stradaos.launcher.opel`, version `2.21.2-opel`, versionCode 54; minSdk remains 16.

Initial port validation: Debug/Opel builds and lint completed; no Errors/Fatals on changed Opel Java lines. The full lint report still contains existing errors. No emulator/device run was performed during the initial port.

## Subsequent menu refinement

- One design choice: **StradaOS** or **Opel Style**. Opel Style directly selects the compact Opel dashboard; the separate layout selector is removed.
- Existing Opel or compact selections migrate to Opel Style. Selecting StradaOS restores the standard layout and its saved accent/theme settings.
- Accent-color controls are absent from Opel Style settings and setup; its red accent is fixed. Dark, Light, Auto, and System modes remain selectable.
- All repository Markdown documentation is in English; app translations remain multilingual.
