## Default vehicle photo

The bundled transparent Astra J image is the fallback for the Opel edition in
both compact and standard layouts. A saved user photo always takes priority;
removing it restores the bundled image. Tapping or long-pressing the image opens
the existing photo picker/menu. Settings distinguish the default photo from a
configured custom photo. The bundled asset is never copied over the custom file.

Photo validation: Debug/Opel builds passed. On the Android 11 emulator, the actual
Storage/USB picker and preview confirmation saved a replacement image, which
appeared immediately and persisted after restart. Removing it restored the
transparent Astra fallback. No app crash occurred; lint totals were unchanged.

## Selectable projection shortcut

Opel users can choose CarPlay or Android Auto during setup after language
selection, or later in Connections. This choice is hidden in the standard style.
It updates the second large shortcut's label, icon, tap action, long-press app
assignment, Appearance hint, and setup app-review entry. The selection persists
across restarts and style changes; existing installs default to CarPlay.
Existing projection launchers, app assignments, and USB selection are reused.
The separately configurable normal dock is not rewritten.

Projection validation: Debug/Opel builds passed; lint totals remain unchanged
(72 errors, 1 fatal issue, 82 warnings). Android 11 emulator checks covered the
CarPlay default, Connections switching to Android Auto, existing launch actions,
restart persistence, hiding the choice in standard settings/setup, and saving
CarPlay through the Opel setup step. No app crash entry occurred. Manufacturer
projection apps still require compatible hardware and target-device testing.

## Settings matched to the active Opel layout

- Hide standard-only card placement/visibility, gauges, map navigation buttons,
  header Wi-Fi/BT controls, greeting/tag fields, and home maintenance badges.
- Preserve functioning maintenance reminders, units, clock, idle display, system
  tools, and music controls. Idle speed no longer depends on hidden car-card flags.
- Show map controls only for the map panel, and live-map controls only when live
  mode is active. Vehicle name/photo settings follow the vehicle panel.
- Fixed shortcuts hide normal dock mode/count/size/label/icon-style settings and
  unused camera/browser/files assignments. The optional configurable dock retains
  its working count/icon/label controls; unsupported compact side/hidden modes stay hidden.
- With fixed shortcuts, Connections exposes only the selected projection app and
  relevant USB/help controls. The configurable dock retains both projection apps
  and its navigation-app assignment. AA metadata access is described as information rather than artwork
  in compact mode; it remains available when Android Auto is selected.
- Setup skips unsupported greeting/tag/accent fields and reviews actual compact
  shortcuts. Hidden standard preferences and dock assignments are retained.

Settings validation: Debug/Opel builds passed, with unchanged lint totals
(72 errors, 1 fatal issue, 82 warnings). Android 11 emulator checks covered
vehicle/map/live-map settings, fixed/configurable dock controls, projection
choices, unavailable home controls, and return to standard settings. Hidden
standard preferences survived style switches; fixed-shortcut reset retained
saved dock assignments. Opel setup skipped unsupported fields and reviewed
only its real shortcuts. No debug-app crash entry occurred.
