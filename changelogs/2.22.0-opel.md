# StradaOS Opel 2.22.0 — upstream synchronization

Merged upstream `0a7736f` into the fork's `main` without replacing its history.
Source version is `2.22.0-opel`, versionCode 55; minSdk 16 and targetSdk 28 remain.

- Retains Opel Style's single-selector compact layout, fixed accent, separate
  theme preferences, transparent Astra J photo, centered speed/clock, and dock.
- Includes upstream idle display, drawer sorting, GPS sunrise/sunset schedules,
  Chinese, standard orientation refinements, and Android Auto disconnect fixes.
- Standard forced/automatic portrait settings do not alter compact landscape.
- GPS feeds both compact and idle speed even without a standard speed TextView.
- Translation merges retain both upstream strings and Opel strings; Chinese
  includes Opel-specific labels. New Markdown notes remain English.
- Historical screenshot and signed 2.21.2 APK records remain labeled by version.
  Existing 2.21.2 APKs are not outputs of the new source revision.

still has 72 errors, 1 fatal issue, and 82 warnings; task success is not a clean
report because abortOnError is false. API 17 and proprietary head-unit functions
remain target-device checks.

Runtime checks on Android 11/API 30 at 1024 × 600 verified compact shortcuts,
idle speed with simulated GPS at 62 km/h, wake-up touch handling, the combined
style selector, Opel sunrise/sunset controls, Chinese compact labels, and
standard layout/app-order controls. No debug-app crash entry was recorded.
These are emulator checks, not validation of proprietary head-unit services.
