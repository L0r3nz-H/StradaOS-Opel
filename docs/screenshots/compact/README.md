# Compact Opel screenshots

These are actual Android 11/API 30 ARM64 emulator captures at **1024 × 600**,
160 dpi. The UI language is German. Images have not been retouched or recreated.

## Current Opel Style menu — 2026-11-16

- [Appearance menu, dark](06-opel-style-menu-dark-1024x600.png): one selector for
  StradaOS or Opel Style, followed by compact panel/shortcut/speed options.
  The separate layout selector is removed. Opel's accent is fixed; its custom
  accent section is absent below the theme controls.
- [Opel Style dashboard, light](07-opel-style-light-1024x600.png): signed
  `2.21.2-opel` after restart, with centered clock, transparent Astra J image,
  labeled weather temperature, and Radio/CarPlay/Phone/All apps shortcuts.
  Weather is emulator data, not a vehicle-temperature reading.
