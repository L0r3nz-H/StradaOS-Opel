## StradaOS 2.9.4 — Ready for F-Droid-style stores

### New
- **Prepared for IzzyOnDroid and F-Droid.** Installations from F-Droid, Droid-ify, Neo Store, and similar clients receive store updates. GitHub notifications are off by default and optional, with an explanation before enabling them.
- GitHub and website installations retain in-app notifications and updates.

### Fixed
- Compatibility information no longer repeats “Android” in “Android Android 4.2”.
