## StradaOS 2.16.0 — Offline maps

Available under Settings → Map and weather → Offline map.

### New
- **Download country maps in the app:** choose a continent and country, with file size and date shown. Downloads use free OpenStreetMap-derived mapsforge files and run while the head unit remains usable. Connection loss or shutdown does not discard progress; completed maps activate automatically.
- **Complete offline dashboard maps:** use a downloaded map or a `.map` file copied to USB/internal storage, with light and dark rendering.
- **Pause, resume, or cancel downloads**, and delete downloaded maps to free space.
- **Smooth map movement:** interpolate the arrow and map between GPS readings instead of jumping.

### Improved
- Clearer missing-GPS/last-position status messages.
- Settings retain their scroll position after changing an option.
