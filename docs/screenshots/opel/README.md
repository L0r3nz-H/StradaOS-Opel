# Opel Navi 900 Modern — historical screenshots

Actual debug-app captures from commit `7cecef5`, taken on 2026-11-09 in an Android 11 emulator (API 30, ARM64). The app language is German. These are unedited captures, not reconstructed mockups.

- [Dashboard, 1024 × 600](01-dashboard-1024x600.png)
- [Design settings, 1024 × 600](02-design-einstellungen-1024x600.png)
- [App drawer, 1024 × 600](03-apps-1024x600.png)
- [Dashboard, 1920 × 720](04-dashboard-1920x720.png)

The theme was enabled using the debug hook `--es prueba design:opel_navi_900_modern`. Display density was 160 dpi at 1024 × 600 and 240 dpi at 1920 × 720.

The map shows the emulator's last reported position. No media was playing. Radio, Bluetooth, and CarPlay hardware functions were not tested by these captures.

These screenshots document the original two-panel Opel theme. The current selector offers **Opel Style**, which activates the 7-inch compact layout, and no longer exposes the old separate design/layout selectors.
