# StradaOS Opel 2.15.0

Integrated upstream `lordnordic-debug/StradaOS` through `c5bc483340dae9a638771752c6e892eb6cf6665a`, including releases 2.14.0/2.15.0 and subsequent screenshot/debug-hook changes.

- Upstream: left/right player, hidden vehicle card with speed/oil in the header, normal/compact/side dock, vertical player, and collapsible Android Auto/CarPlay panel.
- Upstream: factory-launcher, disable, and uninstall actions.
- Opel compact mode remains independent: four shortcuts, transparent vehicle photo, centered time, optional speed, and light/dark modes.
- Original Opel layout retains its wider cards and supports the new player/dock arrangements.
- APK name `StradaOS Opel`, package `com.stradaos.launcher.opel`, version `2.15.0-opel`, versionCode 45. Uses the 2.13.0 signing key for in-place updates; minSdk remains 16.

Build and lint ran. Android-11 emulator checks covered layouts, demo media, settings, app drawer, and returning to Opel compact mode. Demo tracks are not real radio data. API 17 and manufacturer-specific functions remain to be tested on the target radio.
